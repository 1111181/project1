# 手机待办应用 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `D:\claude\project1` 做出一个手机浏览器上使用的个人待办应用，纯静态、零依赖、数据存本机 `localStorage`，可拖拽排序、可标重要、可写备注，部署到 GitHub Pages。

**Architecture:** 单页应用，`store.js` 是纯函数数据层（状态进、新状态出，不碰 DOM/localStorage/全局时间），`storage.js` 是唯一接触 `localStorage` 的模块，三个视图模块（`list-view` / `detail-view` / `drag`）只通过 store 的 API 改数据。列表视图在状态变化后整体重渲染，详情视图按任务 id 绑定输入框、避免每次按键重渲染。

**Tech Stack:** 原生 HTML / CSS / JavaScript（ES modules）。无构建步骤、无 npm 依赖、无后端。测试用 Node 内置的 `node --test`（本机 Node v24.21.0，需 18+）。

**Spec:** `docs/superpowers/specs/2026-10-15-todo-app-design.md`

## Global Constraints

以下约束适用于**每一个**任务，不再逐条重复：

- **零依赖**：不装任何 npm 包，不引 CDN。只用浏览器原生 API 和 Node 内置模块。
- **无构建**：源码即产物。不改文件名、不打包、不转译。
- **ES modules**：所有 `js/*.js` 用 `import` / `export`。因此**本地预览必须起静态服务器**（`node tools/serve.mjs 8000`），双击 `index.html` 会因 CORS 报错。
- **`store.js` 是纯函数模块**：不碰 DOM、不碰 `localStorage`、不读 `Date.now()`（`now` 由参数注入，默认值也只在函数签名里）。id 也由调用方生成后传入，不在 store 内部生成——这样单测能完全确定。
- **`storage.js` 是唯一接触 `localStorage` 的模块。**
- **禁止用 `innerHTML` 插入用户内容**：任务标题、备注、分组名、子任务文本一律用 `textContent` 或 `document.createTextNode`。这是本项目的 XSS 防线。
- **颜色一律走 CSS 变量**，不写死色值。`js/` 里不出现颜色字符串。
- **间距只用** 4 / 8 / 12 / 16 / 24 / 32 / 48。**字号只 4 档**、**字重只 2 档**（见 spec §6.4）。
- **触控目标 ≥ 44px**（视觉可以更小，用 padding 撑开）。
- **动效 120–240ms**，且全部在 `@media (prefers-reduced-motion: reduce)` 下关闭。
- **不用 Service Worker**（spec §11 明确放弃）。
- 中文界面。所有面向用户的文案是中文。

**本机环境注意**：本机 git 已设 `http.schannelCheckRevoke false`（为连上 GitHub）。Windows 下 git 会把 LF 转 CRLF，出现相关 warning 是正常的，不影响。

## Review Focus

以下是 spec 隐含、但**没有任何一个任务的自动化测试会覆盖**的输入类别。它们最可能让真实使用者踩坑，因此每一条都必须在下面指定的那个任务里补一条手工验证步骤。

1. **任务标题 / 备注 / 分组名里含 HTML 特殊字符**（`<script>alert(1)</script>`、`&`、`"`、emoji）→ 必须原样显示成文本，不执行、不破坏布局。防线是全程用 `textContent`。→ 落在 Task 10、Task 12。
2. **超长文本**（300 字的标题、5000 字的备注、40 字的分组名）→ 标题两行后省略、分组名不撑破顶栏、备注框内部可滚动且页面不横向溢出。→ 落在 Task 10、Task 12。
3. **`localStorage` 写满**（`QuotaExceededError`）→ 不能崩、不能静默失败，要让用户看见提示并知道去导出备份。→ 落在 Task 7（数据层拒绝半截写入）、Task 13（界面提示与导出出口）。
4. **损坏或异常的存储内容**（半截 JSON、重复 id、`tasks` 不是数组、`groupId` 指向不存在的分组）→ 读盘不崩、不静默丢数据；导入时给出可读的拒绝理由；`groupId` 对不上的任务归入已有分组而不是丢弃。→ 落在 Task 6（`parseStored` / `validateImport`）+ Task 7（损坏内容的备份）。
5. **空数据下的操作**（一个任务都没有、某个分组一个任务都没有、把最后一个任务删掉、把分组全删光）→ 空状态文案正确出现，拖拽和渲染不报错。→ 落在 Task 10（空状态与空分组提示）、Task 11（拖入空分组）。

## 与设计文档的偏差汇总

**评审时请重点看这一节。** 下面每一条都是实施计划与 spec 不完全一致的地方，分三类。

### A. 技术修正（spec 写错了，照做会出 bug）

| spec 原文 | 问题 | 计划改为 |
|---|---|---|
| §7「元素上设 `touch-action: none`」 | 任务行铺满整屏，设成 `none` 会让**列表彻底滑不动** | `touch-action: manipulation` + 拖拽开始后在 `touchmove` 里 `preventDefault`（Task 11 Step 1） |

### B. spec 未定义、由计划补上的空白

| # | spec 的空白 | 计划补上的做法 |
|---|---|---|
| 1 | 底部悬浮「＋ 添加任务」加到哪一组（§6.1 画了它，§6.3 只规定了分组标题 `+` 的行为） | 加到**第一个分组的末尾**并滚动过去。只有一个分组时与 `+` 行为一致 |
| 2 | 分组在哪改名、在哪删除（数据模型和 `store` 都有，界面没入口） | 分组标题行右侧补一个 `⋯` 菜单，含「重命名分组」「删除分组」 |
| 3 | 怎么**新建分组** | 顶栏 `⋯` 菜单加「新建分组」，用 `window.prompt` 要名字 |
| 4 | §8 说 `groupId` 对不上的任务「归入未分组」 | 优先归入**已存在的**「未分组」；没有则归入 `order` 最小的分组。**不因为导入而凭空新建分组** |
| 5 | `done: true` 但缺 `completedAt` 怎么补 | 补成 `createdAt`，不补成 `0`（`0` 会显示成 1970 年） |

### C. 主动不做的（spec 提过，但做了反而更糟）

| spec 原文 | 不做的理由 |
|---|---|
| §6.1 任务行右侧的拖拽手柄 `⠿`、「仅在拖拽态显示」 | 长按整行就是拖拽手势（§6.3 已定义），再加手柄是冗余入口，还多占横向空间。整行皆可长按 |
| §6.3「长按任务行 350ms → 轻微震动反馈」 | `navigator.vibrate` 只有安卓支持且常被浏览器策略拦截。做了会时灵时不灵，不如不做 |

### Task 1: store 骨架 —— 常量、id、初始状态、查询函数

只做「读」的部分。所有查询函数都是纯函数，不改状态。

**Files:**
- Create: `js/store.js`
- Create: `tests/store.test.mjs`

**Interfaces:**
- Consumes: 无（这是第一个任务）
- Produces:
  - `SCHEMA_VERSION: 1`
  - `DEFAULT_GROUP_NAME: '未分组'`
  - `newId(prefix: string): string` — 形如 `t_a1b2c3d4e5`
  - `createInitialState(): State` — 一个默认分组、零任务
  - `getGroup(state, groupId): Group | null`
  - `getTask(state, taskId): Task | null`
  - `sortedGroups(state): Group[]` — 按 `order` 升序
  - `tasksInGroup(state, groupId): Task[]` — 本组全部任务（含已完成），按 `order` 升序
  - `activeTasksInGroup(state, groupId): Task[]` — 未完成，按 `order` 升序
  - `doneTasksInGroup(state, groupId): Task[]` — 已完成，按 `order` 升序
  - `subtaskProgress(task): { done: number, total: number } | null` — 没有子任务时返回 `null`

**类型（本项目通篇用这套字段名，后续任务不再重复）:**

```js
// Group
{ id: string, name: string, order: number }

// Task
{
  id: string, groupId: string, title: string, note: string,
  done: boolean, important: boolean, due: string | null,   // due: "YYYY-MM-DD"
  subtasks: Subtask[], createdAt: number, completedAt: number | null, order: number
}

// Subtask
{ id: string, text: string, done: boolean }

// State
{ version: number, groups: Group[], tasks: Task[] }
```

创建 `js/store.js`：

```js
// 数据层：全部是纯函数。
// 不碰 DOM、不碰 localStorage、不读全局时间、不自己生成 id。
// 状态进，新状态出。时间和 id 由调用方传入，单测因此完全确定。

export const SCHEMA_VERSION = 1;
export const DEFAULT_GROUP_NAME = '未分组';

const ID_ALPHABET = 'abcdefghijklmnopqrstuvwxyz0123456789';
const ID_LENGTH = 10;

/**
 * 生成一个 id，形如 `t_a1b2c3d4e5`。
 * 非加密用途，只要碰撞概率足够低即可。
 */
export function newId(prefix) {
  let out = '';
  for (let i = 0; i < ID_LENGTH; i += 1) {
    out += ID_ALPHABET[Math.floor(Math.random() * ID_ALPHABET.length)];
  }
  return `${prefix}_${out}`;
}

/** 全新状态：一个默认分组，零任务。 */
export function createInitialState() {
  return {
    version: SCHEMA_VERSION,
    groups: [{ id: 'g_default', name: DEFAULT_GROUP_NAME, order: 0 }],
    tasks: [],
  };
}

export function getGroup(state, groupId) {
  return state.groups.find((g) => g.id === groupId) ?? null;
}

export function getTask(state, taskId) {
  return state.tasks.find((t) => t.id === taskId) ?? null;
}

/** 分组按 order 升序。order 相同或非法时按 id 兜底，保证顺序稳定。 */
export function sortedGroups(state) {
  return [...state.groups].sort(
    (a, b) => a.order - b.order || a.id.localeCompare(b.id),
  );
}

/**
 * 某分组内的任务，按 order 升序。
 * order 相同或非法时依次按 createdAt、id 兜底，保证顺序稳定且可复现。
 */
export function tasksInGroup(state, groupId) {
  return state.tasks
    .filter((t) => t.groupId === groupId)
    .sort(
      (a, b) =>
        a.order - b.order
        || a.createdAt - b.createdAt
        || a.id.localeCompare(b.id),
    );
}

export function activeTasksInGroup(state, groupId) {
  return tasksInGroup(state, groupId).filter((t) => !t.done);
}

export function doneTasksInGroup(state, groupId) {
  return tasksInGroup(state, groupId).filter((t) => t.done);
}

/** 子任务进度。没有子任务时返回 null，让界面决定不显示这个标记。 */
export function subtaskProgress(task) {
  const total = task.subtasks.length;
  if (total === 0) return null;
  const done = task.subtasks.filter((s) => s.done).length;
  return { done, total };
}
```

```js
// ---------- 内部辅助 ----------

/** 把某个分组的任务按现有顺序重新编号为 0..n-1，消除删除留下的空洞。 */
function renumberGroup(state, groupId) {
  const ordered = tasksInGroup(state, groupId);
  const orderById = new Map(ordered.map((t, i) => [t.id, i]));
  return {
    ...state,
    tasks: state.tasks.map((t) =>
      (t.groupId === groupId ? { ...t, order: orderById.get(t.id) } : t)),
  };
}

/** 追加任务时用的下一个 order。 */
function nextOrderInGroup(state, groupId) {
  const list = tasksInGroup(state, groupId);
  return list.length === 0 ? 0 : list[list.length - 1].order + 1;
}

function replaceTask(state, taskId, updater) {
  return {
    ...state,
    tasks: state.tasks.map((t) => (t.id === taskId ? updater(t) : t)),
  };
}

// ---------- 任务 ----------

/** 新建任务，追加到该分组末尾。分组不存在时原样返回。 */
export function addTask(state, { id, groupId, title }, now = Date.now()) {
  if (!getGroup(state, groupId)) return state;

  const task = {
    id,
    groupId,
    title,
    note: '',
    done: false,
    important: false,
    due: null,
    subtasks: [],
    createdAt: now,
    completedAt: null,
    order: nextOrderInGroup(state, groupId),
  };

  return { ...state, tasks: [...state.tasks, task] };
}

/**
 * 修改任务。只有出现在 patch 里的键会被改。
 * `done` 与 `completedAt` 保持同步：变 true 时写 now，变 false 时置 null，
 * 值没变则不动 completedAt。
 */
export function updateTask(state, taskId, patch, now = Date.now()) {
  const task = getTask(state, taskId);
  if (!task) return state;

  const next = { ...task };

  if ('title' in patch) next.title = patch.title;
  if ('note' in patch) next.note = patch.note;
  if ('due' in patch) next.due = patch.due;
  if ('important' in patch) next.important = Boolean(patch.important);

  if ('done' in patch) {
    const done = Boolean(patch.done);
    if (done !== task.done) {
      next.done = done;
      next.completedAt = done ? now : null;
    }
  }

  // 换组：从原位置摘掉，追加到目标组末尾，再压紧源组
  if ('groupId' in patch && patch.groupId !== task.groupId) {
    if (!getGroup(state, patch.groupId)) return state;

    const without = { ...state, tasks: state.tasks.filter((t) => t.id !== taskId) };
    next.groupId = patch.groupId;
    next.order = nextOrderInGroup(without, patch.groupId);

    return renumberGroup(
      { ...without, tasks: [...without.tasks, next] },
      task.groupId,
    );
  }

  return replaceTask(state, taskId, () => next);
}

export function deleteTask(state, taskId) {
  const task = getTask(state, taskId);
  if (!task) return state;

  const without = { ...state, tasks: state.tasks.filter((t) => t.id !== taskId) };
  return renumberGroup(without, task.groupId);
}

export function toggleTaskDone(state, taskId, now = Date.now()) {
  const task = getTask(state, taskId);
  if (!task) return state;
  return updateTask(state, taskId, { done: !task.done }, now);
}

export function toggleTaskImportant(state, taskId) {
  const task = getTask(state, taskId);
  if (!task) return state;
  return updateTask(state, taskId, { important: !task.important });
}
```

```js
// ---------- 分组 ----------

/** 把分组按现有顺序重新编号为 0..n-1。 */
function renumberGroups(state) {
  const ordered = sortedGroups(state);
  const orderById = new Map(ordered.map((g, i) => [g.id, i]));
  return {
    ...state,
    groups: state.groups.map((g) => ({ ...g, order: orderById.get(g.id) })),
  };
}

export function addGroup(state, { id, name }) {
  const order = state.groups.length === 0
    ? 0
    : Math.max(...state.groups.map((g) => g.order)) + 1;
  return { ...state, groups: [...state.groups, { id, name, order }] };
}

export function renameGroup(state, groupId, name) {
  if (!getGroup(state, groupId)) return state;
  return {
    ...state,
    groups: state.groups.map((g) => (g.id === groupId ? { ...g, name } : g)),
  };
}

/**
 * 删除分组，连带删除组内任务。
 * 删掉最后一个分组时自动补一个默认分组——否则界面没有容器可放任务。
 */
export function deleteGroup(state, groupId) {
  if (!getGroup(state, groupId)) return state;

  let next = {
    ...state,
    groups: state.groups.filter((g) => g.id !== groupId),
    tasks: state.tasks.filter((t) => t.groupId !== groupId),
  };

  if (next.groups.length === 0) {
    next = {
      ...next,
      groups: [{ id: 'g_default', name: DEFAULT_GROUP_NAME, order: 0 }],
    };
  }

  return renumberGroups(next);
}

export function moveGroup(state, groupId, toIndex) {
  const ordered = sortedGroups(state);
  const from = ordered.findIndex((g) => g.id === groupId);
  if (from === -1) return state;

  const to = Math.max(0, Math.min(toIndex, ordered.length - 1));
  if (from === to) return state;

  const reordered = ordered.slice();
  const [moved] = reordered.splice(from, 1);
  reordered.splice(to, 0, moved);

  const orderById = new Map(reordered.map((g, i) => [g.id, i]));
  return {
    ...state,
    groups: state.groups.map((g) => ({ ...g, order: orderById.get(g.id) })),
  };
}
```

**Interfaces:**
- Consumes: Task 1 的 `getTask`、`getGroup`、`tasksInGroup`；Task 2 的 `renumberGroup`
- Produces: `moveTask(state, taskId, toGroupId, toIndex): State`

**`toIndex` 的确切含义**（必须和 Task 11 的拖拽代码对齐）：

> `toIndex` 是**目标分组「未完成任务」列表中的可视化落点下标**，取值范围 `0..active.length`（闭区间）。`toIndex = active.length` 表示落到活跃列表最末。

**换算规则**：目标组内除去被拖动任务后的完整列表记作 `full`，其未完成子序列记作 `active`。

- `active[toIndex]` 存在 → 插到它的前面
- 不存在且有活跃任务 → 插到最后一个活跃任务的后面
- 一个活跃任务都没有 → 插到 `full` 的第 0 位（即在已完成任务之前）

**为什么用「活跃下标」而不是「完整列表下标」**：用户在屏幕上看到并拖拽的是活跃列表，已完成任务收在折叠行里看不见。用视觉下标做接口，界面层不需要知道已完成任务在数组里的位置。取消完成时任务会回到它原来 `order` 附近的位置——这是这个设计的副作用，属于可接受的取舍。

```js
// ---------- 排序 ----------

/**
 * 把任务移动到目标分组的指定位置。
 *
 * toIndex 是「目标分组未完成列表」中的可视化落点下标，范围 0..active.length。
 * 界面看到并拖拽的是活跃列表，已完成任务收在折叠行里，
 * 所以接口用视觉下标，界面层不需要知道已完成任务在数组里的位置。
 */
export function moveTask(state, taskId, toGroupId, toIndex) {
  const task = getTask(state, taskId);
  if (!task) return state;
  if (!getGroup(state, toGroupId)) return state;

  const fromGroupId = task.groupId;

  // 目标组内除去被移动任务后的完整有序列表
  const full = tasksInGroup(state, toGroupId).filter((t) => t.id !== taskId);
  const active = full.filter((t) => !t.done);

  let insertAt;
  const anchor = active[toIndex];
  if (anchor) {
    insertAt = full.indexOf(anchor);
  } else if (active.length > 0) {
    insertAt = full.indexOf(active[active.length - 1]) + 1;
  } else {
    insertAt = 0;
  }

  const reordered = full.slice();
  reordered.splice(insertAt, 0, { ...task, groupId: toGroupId });

  const orderById = new Map(reordered.map((t, i) => [t.id, i]));

  let next = {
    ...state,
    tasks: state.tasks.map((t) => {
      if (t.id === taskId) {
        return { ...t, groupId: toGroupId, order: orderById.get(t.id) };
      }
      if (orderById.has(t.id)) return { ...t, order: orderById.get(t.id) };
      return t;
    }),
  };

  // 换组时源组要压紧
  if (fromGroupId !== toGroupId) next = renumberGroup(next, fromGroupId);

  return next;
}
```

```js
// ---------- 子任务 ----------
// 勾选子任务不改变父任务的完成状态：父任务只由用户自己勾。

export function addSubtask(state, taskId, { id, text }) {
  if (!getTask(state, taskId)) return state;
  return replaceTask(state, taskId, (t) => ({
    ...t,
    subtasks: [...t.subtasks, { id, text, done: false }],
  }));
}

export function updateSubtask(state, taskId, subtaskId, patch) {
  if (!getTask(state, taskId)) return state;
  return replaceTask(state, taskId, (t) => ({
    ...t,
    subtasks: t.subtasks.map((s) => {
      if (s.id !== subtaskId) return s;
      const next = { ...s };
      if ('text' in patch) next.text = patch.text;
      if ('done' in patch) next.done = Boolean(patch.done);
      return next;
    }),
  }));
}

export function deleteSubtask(state, taskId, subtaskId) {
  if (!getTask(state, taskId)) return state;
  return replaceTask(state, taskId, (t) => ({
    ...t,
    subtasks: t.subtasks.filter((s) => s.id !== subtaskId),
  }));
}
```

**Interfaces:**
- Consumes: Task 1 的 `SCHEMA_VERSION`、`DEFAULT_GROUP_NAME`、`createInitialState`、`sortedGroups`；Task 2/3 的 `renumberGroup` / `renumberGroups`
- Produces:
  - `normalizeState(data): { ok: true, state, repaired: string[] } | { ok: false, reason: string }`
  - `validateImport(data): { ok: true, state, repaired } | { ok: false, reason }`
  - `parseStored(rawString): { state, status, warning, readonly }`，`status` 取值 `'empty' | 'ok' | 'migrated' | 'corrupt' | 'readonly'`

**两条不同的容错策略**（这是有意的，别写成一样）：

- **读本地存储**（`parseStored`）：整体不可解析 → 归为 `corrupt`，界面用空列表启动，但调用方**必须先把原始字符串备份到另一个键**（Task 7 做）。
- **导入文件**（`validateImport`）：结构性错误 → **拒绝**，不改动现有数据。

两者共用 `normalizeState` 做逐字段校验。可安全修复的问题（`groupId` 对不上、`order` 有空洞、`due` 格式非法、`done` 却没有 `completedAt`）就地修复并记进 `repaired`，让界面能告诉用户发生了什么。

**两处 spec 没写死、由本计划定下的行为**：

- **`groupId` 对不上的任务归到哪**：spec §8 说「归入『未分组』」。本计划定为：优先归入**已存在的、名字等于 `DEFAULT_GROUP_NAME` 的分组**；没有这样的分组时归入**按 `order` 排第一个的分组**。**不因为导入而凭空新建分组**——导入一个文件却多出一个分组，比把任务放进第一个分组更让人意外。
- **`done: true` 但缺 `completedAt`**：补成 `createdAt`，不补成 `0`（`0` 会显示成 1970 年）。

```js
function isPlainObject(value) {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

const DUE_RE = /^\d{4}-\d{2}-\d{2}$/;

/**
 * 把任意值规范化成合法 State。
 * 返回 { ok: true, state, repaired } 或 { ok: false, reason }。
 *
 * 结构性错误一律拒绝；可安全修复的（分组对不上、字段类型不对、
 * order 有空洞、done 与 completedAt 不同步）就地修复并记进 repaired。
 */
export function normalizeState(data) {
  if (!isPlainObject(data)) return { ok: false, reason: '数据不是一个对象' };
  if (typeof data.version !== 'number') return { ok: false, reason: '缺少 version 字段' };
  if (!Array.isArray(data.groups)) return { ok: false, reason: 'groups 不是数组' };
  if (!Array.isArray(data.tasks)) return { ok: false, reason: 'tasks 不是数组' };

  const repaired = [];

  // --- 分组 ---
  const groups = [];
  const groupIds = new Set();
  for (const raw of data.groups) {
    if (!isPlainObject(raw)) return { ok: false, reason: 'groups 里有不是对象的东西' };
    if (typeof raw.id !== 'string' || raw.id === '') {
      return { ok: false, reason: '有分组缺少 id' };
    }
    if (groupIds.has(raw.id)) return { ok: false, reason: `分组 id 重复：${raw.id}` };
    groupIds.add(raw.id);
    groups.push({
      id: raw.id,
      name: typeof raw.name === 'string' ? raw.name : DEFAULT_GROUP_NAME,
      order: Number.isFinite(raw.order) ? raw.order : groups.length,
    });
  }

  if (groups.length === 0) {
    groups.push({ id: 'g_default', name: DEFAULT_GROUP_NAME, order: 0 });
    groupIds.add('g_default');
    repaired.push('一个分组都没有，已补上默认分组');
  }

  // groupId 对不上时的落点：优先已存在的「未分组」，否则 order 最小的分组。
  // 不因为导入而凭空新建分组——那比把任务放进第一个分组更让人意外。
  const orderedGroups = [...groups].sort(
    (a, b) => a.order - b.order || a.id.localeCompare(b.id),
  );
  const fallbackGroupId = (
    orderedGroups.find((g) => g.name === DEFAULT_GROUP_NAME) ?? orderedGroups[0]
  ).id;

  // --- 任务 ---
  const tasks = [];
  const taskIds = new Set();
  for (const raw of data.tasks) {
    if (!isPlainObject(raw)) return { ok: false, reason: 'tasks 里有不是对象的东西' };
    if (typeof raw.id !== 'string' || raw.id === '') {
      return { ok: false, reason: '有任务缺少 id' };
    }
    if (taskIds.has(raw.id)) return { ok: false, reason: `任务 id 重复：${raw.id}` };
    if (typeof raw.title !== 'string') {
      return { ok: false, reason: `任务 ${raw.id} 缺少标题` };
    }
    if (raw.subtasks !== undefined && !Array.isArray(raw.subtasks)) {
      return { ok: false, reason: `任务 ${raw.id} 的 subtasks 不是数组` };
    }
    taskIds.add(raw.id);

    let groupId = raw.groupId;
    if (!groupIds.has(groupId)) {
      groupId = fallbackGroupId;
      repaired.push(`任务「${raw.title}」的分组不存在，已改归到别的分组`);
    }

    const subtasks = [];
    for (const sub of Array.isArray(raw.subtasks) ? raw.subtasks : []) {
      if (!isPlainObject(sub)) continue;
      if (typeof sub.id !== 'string' || typeof sub.text !== 'string') continue;
      subtasks.push({ id: sub.id, text: sub.text, done: Boolean(sub.done) });
    }

    const createdAt = Number.isFinite(raw.createdAt) ? raw.createdAt : 0;
    const done = Boolean(raw.done);

    tasks.push({
      id: raw.id,
      groupId,
      title: raw.title,
      note: typeof raw.note === 'string' ? raw.note : '',
      done,
      important: Boolean(raw.important),
      due: typeof raw.due === 'string' && DUE_RE.test(raw.due) ? raw.due : null,
      subtasks,
      createdAt,
      // 补 createdAt 而不是 0：0 会显示成 1970 年
      completedAt: done
        ? (Number.isFinite(raw.completedAt) ? raw.completedAt : createdAt)
        : null,
      order: Number.isFinite(raw.order) ? raw.order : 0,
    });
  }

  // --- 压紧 order ---
  let state = { version: SCHEMA_VERSION, groups, tasks };
  for (const g of groups) state = renumberGroup(state, g.id);
  state = renumberGroups(state);

  return { ok: true, state, repaired };
}

/**
 * 校验一份待导入的备份。
 * 结构性错误一律拒绝，不改动现有数据。允许规范化时给出 repaired 供界面提示。
 */
export function validateImport(data) {
  if (!isPlainObject(data)) {
    return { ok: false, reason: '文件内容不是一个 JSON 对象，可能选错了文件。' };
  }
  if (typeof data.version !== 'number') {
    return { ok: false, reason: '文件里没有 version 字段，可能不是本应用导出的备份。' };
  }
  if (data.version > SCHEMA_VERSION) {
    return {
      ok: false,
      reason: `备份来自更新的版本（v${data.version}），当前应用只支持到 v${SCHEMA_VERSION}。`,
    };
  }

  const result = normalizeState(data);
  if (!result.ok) return { ok: false, reason: result.reason };
  return { ok: true, state: result.state, repaired: result.repaired };
}

/**
 * 把 localStorage 里的原始字符串解析成 state。
 * 返回 { state, status, warning, readonly }：
 *   status: 'empty' | 'ok' | 'migrated' | 'corrupt' | 'readonly'
 * readonly 为 true 时界面应进入只读，不要写回，避免把新版数据写坏。
 */
export function parseStored(rawString) {
  if (rawString === null || rawString === undefined || rawString === '') {
    return { state: createInitialState(), status: 'empty', warning: null, readonly: false };
  }

  let data;
  try {
    data = JSON.parse(rawString);
  } catch {
    return {
      state: createInitialState(),
      status: 'corrupt',
      warning: '本地数据无法解析，原始内容已备份，现在从空列表开始。',
      readonly: false,
    };
  }

  if (isPlainObject(data) && typeof data.version === 'number' && data.version > SCHEMA_VERSION) {
    const relaxed = normalizeState({ ...data, version: SCHEMA_VERSION });
    return {
      state: relaxed.ok ? relaxed.state : createInitialState(),
      status: 'readonly',
      warning: '本地数据来自更新版本的应用。为避免写坏，现在处于只读状态，改动不会被保存。',
      readonly: true,
    };
  }

  const result = normalizeState(data);
  if (!result.ok) {
    return {
      state: createInitialState(),
      status: 'corrupt',
      warning: `本地数据结构异常（${result.reason}），原始内容已备份，现在从空列表开始。`,
      readonly: false,
    };
  }

  const status = data.version < SCHEMA_VERSION ? 'migrated' : 'ok';
  return { state: result.state, status, warning: null, readonly: false };
}
```

```js
// 唯一接触 localStorage 的模块。
// 其余模块一律通过 createStorage 返回的接口读写，方便测试与替换。

import { parseStored, createInitialState, SCHEMA_VERSION } from './store.js';

export const STORAGE_KEY = 'todo.v1';
export const CORRUPT_KEY_PREFIX = 'todo.v1.corrupt.';

/**
 * 拿一个真的能用的 localStorage；拿不到就返回 null。
 * 隐私模式、被策略禁用、设了只读都会让 setItem 抛异常。
 */
export function getBackend() {
  try {
    const backend = globalThis.localStorage;
    if (!backend) return null;
    const probe = '__todo_probe__';
    backend.setItem(probe, '1');
    backend.removeItem(probe);
    return backend;
  } catch {
    return null;
  }
}

/** 写盘与导出共用的载荷。 */
export function toPayload(state, now = Date.now()) {
  return {
    version: SCHEMA_VERSION,
    savedAt: now,
    groups: state.groups,
    tasks: state.tasks,
  };
}

/** 把异常翻译成一个短标识，界面据此决定提示文案。 */
function classify(err) {
  if (err && (err.name === 'QuotaExceededError' || err.code === 22)) return 'quota';
  return 'unknown';
}

export function createStorage(backend = getBackend()) {
  const available = backend !== null && backend !== undefined;

  return {
    available,

    /**
     * 读盘。返回 { state, status, warning, readonly }。
     * status 可能是 empty / ok / migrated / corrupt / readonly / unavailable。
     * status 为 corrupt 时，先把原始字符串备份到另一个键再返回——宁可留一份
     * 看不懂的垃圾，也不能把用户数据静默丢掉。
     */
    load(now = Date.now()) {
      if (!available) {
        return {
          state: createInitialState(),
          status: 'unavailable',
          warning: '这个浏览器不允许保存本地数据（可能是隐私模式）。现在可以正常使用，但关掉页面后内容会丢失。',
          readonly: true,
        };
      }

      let raw = null;
      try {
        raw = backend.getItem(STORAGE_KEY);
      } catch {
        return {
          state: createInitialState(),
          status: 'unavailable',
          warning: '读取本地数据失败。现在可以正常使用，但关掉页面后内容会丢失。',
          readonly: true,
        };
      }

      const result = parseStored(raw);

      if (result.status === 'corrupt' && raw !== null && raw !== undefined) {
        try {
          backend.setItem(`${CORRUPT_KEY_PREFIX}${now}`, raw);
        } catch {
          // 备份失败也不能丢原数据，更不能在这里崩掉
        }
      }

      return result;
    },

    /** 写盘。返回 { ok: true } 或 { ok: false, reason }。 */
    save(state, now = Date.now()) {
      if (!available) return { ok: false, reason: 'unavailable' };
      try {
        backend.setItem(STORAGE_KEY, JSON.stringify(toPayload(state, now)));
        return { ok: true };
      } catch (err) {
```

```js
// hash 路由：#/ 走列表，#/task/<id> 走详情。
// 用 hash 而不是 History API：hash 变更在 GitHub Pages 上不需要服务端配合，
// 而且手机浏览器的返回键天然就能用。

export const ROUTE_LIST = 'list';
export const ROUTE_TASK = 'task';

/**
 * 把 location.hash 解析成路由对象。
 * 任何认不出来的输入都退化成列表——用户永远不该看到一片空白。
 */
export function parseHash(hash) {
  const raw = typeof hash === 'string' ? hash : '';
  const path = raw.replace(/^#/, '').replace(/^\/+/, '');

  if (path === '') return { name: ROUTE_LIST, taskId: null };

  const parts = path.split('/').filter(Boolean);
  if (parts[0] === 'task' && parts.length === 2) {
    return { name: ROUTE_TASK, taskId: decodeURIComponent(parts[1]) };
  }

  return { name: ROUTE_LIST, taskId: null };
}

export function taskHash(taskId) {
  return `#/task/${encodeURIComponent(taskId)}`;
}

export function listHash() {
  return '#/';
}

export function createRouter(onChange) {
  const handle = () => onChange(parseHash(window.location.hash));

  window.addEventListener('hashchange', handle);

  return {
    /** 立刻按当前地址派发一次，让首屏也走同一条路径。 */
    start() {
      handle();
    },
    goToList() {
      window.location.hash = listHash();
    },
    goToTask(taskId) {
      window.location.hash = taskHash(taskId);
    },
    stop() {
      window.removeEventListener('hashchange', handle);
    },
  };
}
```

  - `actions` 需要提供：`openTask(id)`、`toggleDone(id)`、`deleteTask(id)`、`addTask(groupId, title)`、`renameGroup(id, name)`、`deleteGroup(id)`
    （`toggleImportant` 不在列表视图的契约里——列表只**显示**重要状态（淡红底 + 复选框红点），切换只在详情页做）
  - 任务行的 DOM 契约（Task 11 的拖拽依赖它）：`<li class="task" data-task-id="...">`，分组容器 `<ul class="task-list" data-group-id="...">`，分组区块 `<section class="group" data-group-id="...">`

**spec 没写死、由本计划补上的 UI 缺口**：

spec §6.1 的分组标题行只有「名字 + `+`」，但数据模型有分组名，`store` 也有 `renameGroup`——spec 全篇没说在哪里改名、在哪里删分组。本计划在分组标题行补一个 `⋯` 按钮，菜单里放「重命名分组」「删除分组」。删除时用 `window.confirm` 二次确认，并说清会连带删掉组内几个任务。

**spec 没写死、由本计划定下的内联添加行为**：

- 回车 → 添加并清空输入框，**保持焦点**，方便连续录入
- 输入框为空时回车 / 按 Esc → 关闭输入行
- 失焦 → 内容非空则先添加，然后关闭输入行

创建 `js/list-view.js`：

```js
// 首页：分组与任务的渲染和交互。

import {
  sortedGroups,
  activeTasksInGroup,
  doneTasksInGroup,
  tasksInGroup,
  subtaskProgress,
} from './store.js';

function el(tag, className) {
  const node = document.createElement(tag);
  if (className) node.className = className;
  return node;
}

/** '2026-10-20' -> '10-20'；不是今年的带上年份，避免误读。 */
export function formatDue(due, today = new Date()) {
  const [year, month, day] = due.split('-');
  if (Number(year) === today.getFullYear()) {
    return `${Number(month)}-${Number(day)}`;
  }
  return `${year}-${month}-${day}`;
}

export function createListView({ root, actions }) {
  // 只属于界面、不进数据模型的临时状态
  const ui = {
    collapsed: new Set(),
    expandedDone: new Set(),
    addingGroupId: null,
    renamingGroupId: null,
    focusAdd: false,
    focusRename: false,
    closingAdd: false,
  };

  let state = null;
  let openMenu = null;
  let painting = false;

  // ---------- 弹出菜单 ----------

  function closeMenu() {
    if (openMenu) {
      openMenu.remove();
      openMenu = null;
    }
  }

  document.addEventListener('click', closeMenu);

  function showMenu(anchor, items) {
    closeMenu();

    const menu = el('div', 'menu');
    menu.setAttribute('role', 'menu');

    for (const item of items) {
      const button = el('button', 'menu__item');
      button.type = 'button';
      if (item.danger) button.classList.add('menu__item--danger');
      button.textContent = item.label;
      button.addEventListener('click', () => {
        closeMenu();
        item.run();
      });
      menu.append(button);
    }

    document.body.append(menu);

    // 贴住锚点右下角，并保证不超出视口
    const rect = anchor.getBoundingClientRect();
    const width = menu.offsetWidth;
    const height = menu.offsetHeight;
    const left = Math.min(
      Math.max(8, rect.right - width),
      Math.max(8, window.innerWidth - width - 8),
    );
    const below = rect.bottom + 4;
    const top = below + height > window.innerHeight - 8
      ? Math.max(8, rect.top - height - 4)
      : below;

    menu.style.left = `${left}px`;
    menu.style.top = `${top}px`;

    openMenu = menu;
  }

  // ---------- 空状态 ----------

  function renderEmptyState() {
    const box = el('div', 'empty-state');

    const title = el('p', 'empty-state__title');
    title.textContent = '还没有任务';

    const hint = el('p', 'empty-state__hint');
    hint.textContent = '点下面的按钮加一个';

    box.append(title, hint);
    return box;
  }

  // ---------- 任务行 ----------

  function renderTask(task) {
    const li = el('li', 'task');
    li.dataset.taskId = task.id;
    if (task.important) li.classList.add('task--important');

    const check = el('button', 'task__check');
    check.type = 'button';
    check.setAttribute('role', 'checkbox');
    check.setAttribute('aria-checked', 'false');
    check.setAttribute('aria-label', `完成「${task.title}」`);
    check.append(el('span', 'task__check-dot'));
    check.addEventListener('click', (event) => {
      event.stopPropagation();
      actions.toggleDone(task.id);
    });

    const body = el('div', 'task__body');

    const title = el('span', 'task__title');
    // textContent：用户内容绝不走 innerHTML
    title.textContent = task.title;
    body.append(title);

    const meta = el('div', 'task__meta');

    if (task.due) {
      const due = el('span', 'task__meta-item');
      due.textContent = formatDue(task.due);
      meta.append(due);
    }

    const progress = subtaskProgress(task);
    if (progress) {
      const item = el('span', 'task__meta-item');
      item.textContent = `${progress.done}/${progress.total}`;
      meta.append(item);
    }

    if (task.note.trim() !== '') {
      const mark = el('span', 'task__meta-item');
      mark.textContent = '≡';
      mark.title = '有备注';
      meta.append(mark);
    }

    if (meta.childElementCount > 0) body.append(meta);

    li.append(check, body);
    li.addEventListener('click', () => actions.openTask(task.id));

    return li;
  }

  function renderDoneTask(task) {
    const li = el('li', 'task task--done');
    li.dataset.taskId = task.id;

    const check = el('button', 'task__check');
    check.type = 'button';
    check.setAttribute('role', 'checkbox');
    check.setAttribute('aria-checked', 'true');
    check.setAttribute('aria-label', `取消完成「${task.title}」`);

    const tick = el('span', 'task__check-tick');
    tick.textContent = '✓';
    tick.setAttribute('aria-hidden', 'true');
    check.append(tick);

    check.addEventListener('click', (event) => {
      event.stopPropagation();
      actions.toggleDone(task.id);
    });

    const body = el('div', 'task__body');
    const title = el('span', 'task__title');
    title.textContent = task.title;
    body.append(title);

    const remove = el('button', 'icon-button task__delete');
    remove.type = 'button';
    remove.textContent = '×';
    remove.setAttribute('aria-label', `删除「${task.title}」`);
    remove.addEventListener('click', (event) => {
      event.stopPropagation();
      actions.deleteTask(task.id);
    });

    li.append(check, body, remove);
    li.addEventListener('click', () => actions.openTask(task.id));

    return li;
  }

  // ---------- 内联添加 ----------

  function renderAddRow(groupId) {
    const row = el('div', 'add-row');

    const input = el('input', 'add-row__input');
    input.type = 'text';
    input.placeholder = '写点什么，回车确认';
    input.autocomplete = 'off';
    input.setAttribute('aria-label', '新任务标题');
    input.setAttribute('enterkeyhint', 'done');

    input.addEventListener('keydown', (event) => {
      if (event.key === 'Enter') {
        event.preventDefault();
        const title = input.value.trim();
        if (title === '') {
          closeAddRow();
          return;
        }
        input.value = '';
        ui.focusAdd = true; // 下一次重渲染后把焦点还回来，方便连续录入
        actions.addTask(groupId, title);
      } else if (event.key === 'Escape') {
        event.preventDefault();
        closeAddRow();
      }
    });

    input.addEventListener('blur', () => {
      // 移除一个持有焦点的元素会同步触发 blur，那时输入行已经在关了，别再走一遍
      if (ui.closingAdd) return;
      const title = input.value.trim();
      if (title !== '') actions.addTask(groupId, title);
      closeAddRow();
    });

    row.append(input);
    return row;
  }

  function closeAddRow() {
    if (ui.closingAdd) return;
    ui.closingAdd = true;
    ui.addingGroupId = null;
    ui.focusAdd = false;
    queueMicrotask(() => {
      ui.closingAdd = false;
      render();
    });
  }

  // ---------- 已完成折叠区 ----------

  function renderDoneSection(group, done) {
    const box = el('div', 'done-section');
    const expanded = ui.expandedDone.has(group.id);

    const toggle = el('button', 'done-section__toggle');
    toggle.type = 'button';
    toggle.setAttribute('aria-expanded', String(expanded));
    toggle.textContent = `已完成 ${done.length} 项`;
    toggle.addEventListener('click', () => {
      if (expanded) ui.expandedDone.delete(group.id);
      else ui.expandedDone.add(group.id);
      render();
    });
    box.append(toggle);

    if (expanded) {
      const list = el('ul', 'task-list');
      for (const task of done) list.append(renderDoneTask(task));
      box.append(list);
    }

    return box;
  }

  // ---------- 分组 ----------

  function renderGroup(group) {
    const section = el('section', 'group');
    section.dataset.groupId = group.id;

    const isCollapsed = ui.collapsed.has(group.id);
    const active = activeTasksInGroup(state, group.id);
    const done = doneTasksInGroup(state, group.id);

    const header = el('header', 'group__header');

    if (ui.renamingGroupId === group.id) {
      const input = el('input', 'group__rename');
      input.type = 'text';
      input.value = group.name;
      input.autocomplete = 'off';
      input.setAttribute('aria-label', '分组名称');

      const finish = (save) => {
        if (ui.renamingGroupId !== group.id) return;
        const name = input.value.trim();
        ui.renamingGroupId = null;
        if (save && name !== '' && name !== group.name) {
          actions.renameGroup(group.id, name);
        } else {
          render();
        }
      };

      input.addEventListener('keydown', (event) => {
        if (event.key === 'Enter') {
          event.preventDefault();
          finish(true);
        } else if (event.key === 'Escape') {
          event.preventDefault();
          finish(false);
        }
      });
      input.addEventListener('blur', () => finish(true));

      header.append(input);
    } else {
      const toggle = el('button', 'group__toggle');
      toggle.type = 'button';
      toggle.setAttribute('aria-expanded', String(!isCollapsed));

      const caret = el('span', 'group__caret');
      caret.textContent = isCollapsed ? '▸' : '▾';
      caret.setAttribute('aria-hidden', 'true');

      const name = el('span', 'group__name');
      if (group.name === '') {
        name.textContent = '未命名分组';
        name.classList.add('group__name--placeholder');
      } else {
        name.textContent = group.name;
      }

      const count = el('span', 'group__count');
      if (active.length > 0) count.textContent = String(active.length);

      toggle.append(caret, name, count);
      toggle.addEventListener('click', () => {
        if (ui.collapsed.has(group.id)) ui.collapsed.delete(group.id);
        else ui.collapsed.add(group.id);
        render();
      });

      const more = el('button', 'icon-button group__more');
      more.type = 'button';
      more.textContent = '⋯';
      more.setAttribute('aria-label', `「${group.name}」的更多操作`);
      more.addEventListener('click', (event) => {
        event.stopPropagation();
        showMenu(more, [
          {
            label: '重命名分组',
            run: () => {
              ui.renamingGroupId = group.id;
              ui.focusRename = true;
              render();
            },
          },
          {
            label: '删除分组',
            danger: true,
            run: () => confirmDeleteGroup(group),
          },
        ]);
      });

      const add = el('button', 'icon-button group__add');
      add.type = 'button';
      add.textContent = '＋';
      add.setAttribute('aria-label', `在「${group.name}」添加任务`);
      add.addEventListener('click', (event) => {
        event.stopPropagation();
        startAddInGroup(group.id);
      });

      header.append(toggle, more, add);
    }

    section.append(header);

    if (!isCollapsed) {
      const list = el('ul', 'task-list');
      list.dataset.groupId = group.id;

      for (const task of active) list.append(renderTask(task));

      if (active.length === 0 && ui.addingGroupId !== group.id) {
        const blank = el('li', 'task-list__blank');
        blank.textContent = '这个分组还没有任务';
        list.append(blank);
      }

      section.append(list);

      if (ui.addingGroupId === group.id) section.append(renderAddRow(group.id));

      if (done.length > 0) section.append(renderDoneSection(group, done));
    }

    return section;
  }

  function confirmDeleteGroup(group) {
    const count = tasksInGroup(state, group.id).length;
    const extra = count > 0 ? `，组内的 ${count} 个任务也会一起删掉` : '';
    const ok = window.confirm(`确定删除分组「${group.name}」吗？${extra}。\n\n这个操作没法撤销。`);
    if (ok) actions.deleteGroup(group.id);
  }

  // ---------- 渲染入口 ----------

  function render(next) {
    if (next) state = next;
    if (!state || painting) return;

    painting = true;
    try {
      root.textContent = '';

      const groups = sortedGroups(state);
      const allEmpty = groups.every((g) => tasksInGroup(state, g.id).length === 0);
      if (allEmpty) root.append(renderEmptyState());

      for (const group of groups) root.append(renderGroup(group));

      if (ui.focusAdd && ui.addingGroupId) {
        ui.focusAdd = false;
        const input = root.querySelector('.add-row__input');
        if (input) {
          input.focus();
          const end = input.value.length;
          input.setSelectionRange(end, end);
        }
      }

      if (ui.focusRename && ui.renamingGroupId) {
        ui.focusRename = false;
        const input = root.querySelector('.group__rename');
        if (input) {
          input.focus();
          input.select();
        }
      }
    } finally {
      painting = false;
    }
  }

  function startAddInGroup(groupId) {
    ui.addingGroupId = groupId;
    ui.focusAdd = true;
    ui.collapsed.delete(groupId); // 折叠着也能加
    render();

    const input = root.querySelector('.add-row__input');
    if (input) input.scrollIntoView({ block: 'center' });
  }

  return { render, startAddInGroup };
}
```

```js
import { createRouter, ROUTE_TASK } from './router.js';

  getGroup,

const notice = document.getElementById('notice');
const viewList = document.getElementById('view-list');
const viewDetail = document.getElementById('view-detail');
const detailGroupName = document.getElementById('detail-group-name');
const groupList = document.getElementById('group-list');
const addTaskButton = document.getElementById('add-task-button');

const storage = createStorage();
const loaded = storage.load();

let state = loaded.state;
let warnedAboutSave = false;

/** 顶部提示条。传空字符串就收起。 */
function showNotice(text) {
  notice.textContent = text ?? '';
  notice.hidden = !text;
}

/** 写盘。结构性改动立刻写，不等防抖。 */
function persist() {
  if (loaded.readonly) return;

  const result = storage.save(state);

  if (result.ok) {
    warnedAboutSave = false;
    return;
  }
  if (warnedAboutSave) return;

  warnedAboutSave = true;
  showNotice(
```

### Task 11: 拖拽排序

全项目技术风险最高的一处。手机上**没有**可用的现成方案：HTML5 的 Drag and Drop API 在移动端浏览器根本不触发。

**Files:**
- Create: `js/drag.js`
- Modify: `js/list-view.js`（接入两处拖拽）
- Modify: `js/app.js`（加 `moveTask` / `moveGroup` 动作）
- Modify: `css/app.css`（拖拽相关样式）

**Interfaces:**
- Consumes: Task 4 的 `moveTask`、Task 3 的 `moveGroup`；Task 10 建立的 DOM 契约（`.task[data-task-id]`、`.task-list[data-group-id]`、`section.group[data-group-id]`）
- Produces: `attachSortable(container, options)`
  - `options.itemSelector` — 可拖拽项（`.task` / `.group`）
  - `options.handleSelector` — 可选，必须按在这里才算（分组传 `.group__header`）
  - `options.ignoreSelector` — 可选，按在这些上不触发拖拽，默认 `'button, input, textarea, select, a, label'`
  - `options.draggingClass` — 拖拽中加到元素上的类名
  - `options.scrollEl` — 自动滚动的容器
  - `options.containerOf(node)` — 由指针下的元素反查「所属的可放置列表」
  - `options.onDrop(item, { listEl, index })`
  - `options.onStart(item)` / `options.onEnd()`

**⚠️ 对 spec §7 的一处技术修正（重要）**

spec §7 写「元素上设 `touch-action: none`，否则浏览器会把滑动解释成页面滚动」。**照做会把整个列表的滚动弄坏**——任务行铺满屏幕，`touch-action: none` 意味着手指按在任务上往下滑时页面纹丝不动。

本计划的正确做法：

- 任务行和分组标题设 `touch-action: manipulation`（允许滚动和缩放，只去掉双击缩放的延迟），**不设 `none`**
- 长按判定成立后（350ms、位移 < 8px），在 window 上以 `{ passive: false }` 监听 `touchmove` 并 `preventDefault()`，**从这一刻起**才阻止滚动
- 移动过程中如果浏览器已经判定为滚动手势，会发 `pointercancel`——收到它就当作拖拽取消，不能让界面停在一个半拖拽的状态

**实现方式：占位元素 + 脱离文档流**

拖拽开始后把元素移到 `document.body` 并 `position: fixed` 贴在原位置，原处插一个等高的占位元素。指针移动时只动 `transform`，同时把占位元素插到目标位置。松手时把元素放回占位元素处、清掉内联样式。这样跨分组拖动时布局由浏览器自然重排，不需要手动计算兄弟元素位移。

- [ ] **Step 1: 写拖拽模块**

创建 `js/drag.js`：

```js
// 通用长按拖拽排序。任务列表和分组列表共用。
//
// 为什么不用 HTML5 的 dragstart/dragover：那套 API 在移动端浏览器上根本不触发。
// 手机上只能用 Pointer Events 自己实现。

const LONG_PRESS_MS = 350;
const MOVE_TOLERANCE = 8;   // 超过这个位移就判定为滚动，取消长按
const EDGE_ZONE = 64;       // 距容器上下边缘多少像素内开始自动滚动
const MAX_SCROLL_STEP = 14; // 每帧最多滚多少像素

export function attachSortable(container, options) {
  const {
    itemSelector,
    handleSelector = null,
    ignoreSelector = 'button, input, textarea, select, a, label',
    draggingClass,
    scrollEl = container,
    containerOf,
    onDrop,
    onStart,
    onEnd,
  } = options;

  let press = null;
  let drag = null;

  function cancelPress() {
    if (press) {
      clearTimeout(press.timer);
      press = null;
    }
  }

  function handlePointerDown(event) {
    if (drag || (event.button !== undefined && event.button !== 0)) return;

    if (event.target.closest(ignoreSelector)) return;

    const item = event.target.closest(itemSelector);
    if (!item || !container.contains(item)) return;

    // 已完成折叠区里的任务不参与拖拽：那里的顺序对用户没有意义
    if (item.closest('.done-section')) return;

    if (handleSelector && !event.target.closest(handleSelector)) return;

    const startX = event.clientX;
    const startY = event.clientY;

    press = {
      item,
      startX,
      startY,
      timer: setTimeout(() => {
        press = null;
        beginDrag(item, startX, startY);
      }, LONG_PRESS_MS),
    };
  }

  function beginDrag(item, startX, startY) {
    const rect = item.getBoundingClientRect();

    const placeholder = document.createElement(item.tagName);
    placeholder.className = 'drag-placeholder';
    placeholder.style.height = `${rect.height}px`;
    placeholder.style.pointerEvents = 'none';
    item.parentNode.insertBefore(placeholder, item);

    document.body.append(item);
    item.classList.add(draggingClass);
    item.style.position = 'fixed';
    item.style.left = `${rect.left}px`;
    item.style.top = `${rect.top}px`;
    item.style.width = `${rect.width}px`;
    item.style.margin = '0';

    drag = {
      item,
      placeholder,
      startX,
      startY,
      lastX: startX,
      lastY: startY,
      target: null,
      rafId: 0,
    };

    // 拖拽期间禁掉文本选择与系统长按菜单
    window.getSelection()?.removeAllRanges();

    if (onStart) onStart(item);
  }

  function scheduleUpdate() {
    if (drag && !drag.rafId) drag.rafId = requestAnimationFrame(update);
  }

  function update() {
    if (!drag) return;
    drag.rafId = 0;

    const { item, placeholder, lastX, lastY } = drag;

    item.style.transform =
      `translate(${lastX - drag.startX}px, ${lastY - drag.startY}px)`;

    // 指针下的元素查所属列表。元素与占位都设了 pointer-events: none，
    // 所以这里拿到的是它们「下面」的真实内容。
    const under = document.elementFromPoint(lastX, lastY);
    const listEl = under ? containerOf(under) : null;

    if (listEl) {
      const items = [...listEl.querySelectorAll(itemSelector)];
      let index = items.length;
      for (let i = 0; i < items.length; i += 1) {
        const rect = items[i].getBoundingClientRect();
        if (lastY < rect.top + rect.height / 2) {
          index = i;
          break;
        }
      }

      const reference = items[index] ?? null;
      if (placeholder.parentNode !== listEl || placeholder.nextSibling !== reference) {
        listEl.insertBefore(placeholder, reference);
      }
      drag.target = { listEl, index };
    }

    // 靠近上下边缘时自动滚动，任务多的时候必需
    const bounds = scrollEl.getBoundingClientRect();
    let step = 0;
    if (lastY < bounds.top + EDGE_ZONE) {
      const ratio = (bounds.top + EDGE_ZONE - lastY) / EDGE_ZONE;
      step = -MAX_SCROLL_STEP * Math.min(1, ratio);
    } else if (lastY > bounds.bottom - EDGE_ZONE) {
      const ratio = (lastY - (bounds.bottom - EDGE_ZONE)) / EDGE_ZONE;
      step = MAX_SCROLL_STEP * Math.min(1, ratio);
    }

    if (step !== 0) {
      scrollEl.scrollTop += step;
      scheduleUpdate(); // 手指不动也要继续滚，所以再排一帧
    }
  }

  function handlePointerMove(event) {
    if (press) {
      const moved = Math.hypot(
        event.clientX - press.startX,
        event.clientY - press.startY,
      );
      if (moved > MOVE_TOLERANCE) cancelPress(); // 判定为滚动，放弃长按
      return;
    }

    if (!drag) return;

    drag.lastX = event.clientX;
    drag.lastY = event.clientY;
    scheduleUpdate();
  }

  function finish(commitDrop) {
    cancelPress();
    if (!drag) return;

    const { item, placeholder, target } = drag;
    if (drag.rafId) cancelAnimationFrame(drag.rafId);

    if (placeholder.parentNode) {
      placeholder.parentNode.insertBefore(item, placeholder);
      placeholder.remove();
    }

    item.classList.remove(draggingClass);
    item.style.position = '';
    item.style.left = '';
    item.style.top = '';
    item.style.width = '';
    item.style.margin = '';
    item.style.transform = '';

    drag = null;

    if (onEnd) onEnd();
    if (commitDrop && target && onDrop) onDrop(item, target);
  }

  function handlePointerUp() {
    finish(true);
  }

  // 浏览器把这次手势判成滚动了，拖拽必须干净地取消
  function handlePointerCancel() {
    finish(false);
  }

  // 长按之后阻止滚动。只在拖拽真的开始时才拦，平时不碰滚动。
  function handleTouchMove(event) {
    if (drag) event.preventDefault();
  }

  // 安卓长按会弹系统菜单，拖拽期间要拦掉
  function handleContextMenu(event) {
    if (drag) event.preventDefault();
  }

  container.addEventListener('pointerdown', handlePointerDown);
  window.addEventListener('pointermove', handlePointerMove);
  window.addEventListener('pointerup', handlePointerUp);
  window.addEventListener('pointercancel', handlePointerCancel);
  window.addEventListener('touchmove', handleTouchMove, { passive: false });
  window.addEventListener('contextmenu', handleContextMenu);

  return function detach() {
    container.removeEventListener('pointerdown', handlePointerDown);
    window.removeEventListener('pointermove', handlePointerMove);
    window.removeEventListener('pointerup', handlePointerUp);
    window.removeEventListener('pointercancel', handlePointerCancel);
    window.removeEventListener('touchmove', handleTouchMove);
    window.removeEventListener('contextmenu', handleContextMenu);
  };
}
```

2. 拖到另一条任务上方 → 占位框跟着移动，其他任务让位
3. 松手 → 元素落回占位框处，顺序已变
4. 刷新页面 → 新顺序还在

**触摸模拟（关键路径）**

5. **单指在任务行上快速上下滑 → 页面正常滚动，绝不触发拖拽**（这是误触防护的核心）
6. 长按一条任务约 0.5 秒 → 轻微浮起，之后手指移动**页面不再滚动**
7. 拖到自己分组的首位 / 末位 → 顺序正确
8. **跨分组**：拖到另一个分组的任务列表中间 → 占位框出现在那个分组里
9. 跨分组松手 → 任务进入目标分组，**两个分组的序号都是连续的**（可以刷新页面确认，刷新后顺序不变说明写盘正确）

11. 拖到一个**空列表的最下方**（占位框落到最后）→ 松手后任务在最后
12. **滚回顶部**：拖拽时把手指移到屏幕顶部边缘不动 → 列表自动向上滚（需要先造 20 条以上任务才有滚动空间）

14. 拖拽中途按浏览器返回键 / 切到别的 App 再回来 → 界面不卡在拖拽态，列表可用
15. 拖**分组标题行** → 分组浮起，上下移动能换顺序；松手后顺序变；刷新后仍是新顺序

### Task 12: 详情视图

**Files:**
- Create: `js/detail-view.js`
- Modify: `js/app.js`（装配详情视图、加防抖保存与三重兜底）
- Modify: `css/app.css`（追加详情页样式）

**Interfaces:**
- Consumes: Task 1 的 `getTask`、`getGroup`、`sortedGroups`；Task 2 的 `updateTask`、`toggleTaskDone`、`toggleTaskImportant`、`deleteTask`；Task 5 的 `addSubtask`、`updateSubtask`、`deleteSubtask`；Task 8 的 `#detail-scroll`、`#detail-back`、`#detail-group-name`；Task 9 的 `router.goToList`
- Produces:
  - `createDetailView({ root, groupNameEl, actions })` → `{ render(state, taskId) }`
  - `actions` 需要提供：`setField(taskId, patch, immediate?)`、`toggleImportant(id)`、`toggleDone(id)`、`addSubtask(taskId, text)`、`toggleSubtask(taskId, subtaskId)`、`setSubtask(taskId, subtaskId, patch, immediate?)`、`deleteSubtask(taskId, subtaskId)`、`deleteTask(taskId)`、`flush()`

**性能与焦点的关键设计**：详情视图**只在任务 id 变化时重建 DOM**。之后每次 `render` 只做「同步」——把状态写回控件，但**跳过当前有焦点的那个控件**。否则每敲一个字都会重建输入框，光标会跳走、输入会丢字。这是本任务最容易写错的地方。

**spec §5 的自动保存落在这一任务**：

- 标题、备注、子任务文本 → `input` 事件触发 `setField(..., immediate = false)` → 200ms 防抖写盘
- 重要、完成、截止日期、分组、子任务增删 → 结构或离散改动 → `immediate = true` → 立刻写盘
- 三重兜底（spec §5 第 3 条）：控件的 `blur`、`document.visibilitychange` 转 `hidden`、`window.pagehide` 与 `window.blur` → 一律调 `flush()` 立刻落盘。手机上切 App、锁屏、被电话打断都是 `visibilitychange`，少了这层会丢最后几个字。

```js
// 任务详情视图：标题、开关、截止日期、分组、备注、子任务、元信息、删除。

import { getTask, getGroup, sortedGroups } from './store.js';

function el(tag, className) {
  const node = document.createElement(tag);
  if (className) node.className = className;
  return node;
}

function stamp(ms) {
  if (!Number.isFinite(ms) || ms <= 0) return '—';
  const d = new Date(ms);
  const pad = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())} `
    + `${pad(d.getHours())}:${pad(d.getMinutes())}`;
}

export function createDetailView({ root, groupNameEl, actions }) {
  const els = {};
  let currentId = null;
  let subtaskKey = '';

  function field(labelText, controlId) {
    const wrap = el('div', 'field');
    const label = el('label', 'field__label');
    label.textContent = labelText;
    if (controlId) label.setAttribute('for', controlId);
    const control = el('div', 'field__control');
    wrap.append(label, control);
    return { wrap, control };
  }

  function metaRow(key, value) {
    const row = el('div', 'detail__meta-row');
    const k = el('dt', 'detail__meta-key');
    k.textContent = key;
    const v = el('dd', 'detail__meta-value');
    v.textContent = value;
    row.append(k, v);
    return row;
  }

  // ---------- 构建（只在任务 id 变化时调用） ----------

  function build(state, task) {
    root.textContent = '';
    subtaskKey = '';

    const form = el('div', 'detail');

    // 标题
    const title = el('input', 'detail__title');
    title.type = 'text';
    title.value = task.title;
    title.placeholder = '任务标题';
    title.autocomplete = 'off';
    title.setAttribute('aria-label', '任务标题');
    title.addEventListener('input', () => actions.setField(task.id, { title: title.value }));
    title.addEventListener('blur', () => actions.flush());
    form.append(title);
    els.title = title;

    // 重要 / 完成
    const toggles = el('div', 'detail__toggles');

    const important = el('button', 'toggle toggle--important');
    important.type = 'button';
    important.setAttribute('role', 'switch');
    const importantDot = el('span', 'toggle__dot');
    const importantText = el('span', 'toggle__text');
    importantText.textContent = '重要';
    important.append(importantDot, importantText);
    important.addEventListener('click', () => actions.toggleImportant(task.id));

    const done = el('button', 'toggle');
    done.type = 'button';
    done.setAttribute('role', 'switch');
    const doneDot = el('span', 'toggle__dot');
    const doneText = el('span', 'toggle__text');
    doneText.textContent = '完成';
    done.append(doneDot, doneText);
    done.addEventListener('click', () => actions.toggleDone(task.id));

    toggles.append(important, done);
    form.append(toggles);
    els.important = important;
    els.done = done;

    // 截止日期
    const dueField = field('截止日期', 'detail-due');
    const dueRow = el('div', 'field__row');
    const due = el('input', 'field__input');
    due.type = 'date';
    due.id = 'detail-due';
    due.addEventListener('change', () => {
      actions.setField(task.id, { due: due.value === '' ? null : due.value }, true);
      actions.flush();
    });
    const dueClear = el('button', 'field__clear');
    dueClear.type = 'button';
    dueClear.textContent = '清除';
    dueClear.addEventListener('click', () => {
      actions.setField(task.id, { due: null }, true);
      actions.flush();
    });
    dueRow.append(due, dueClear);
    dueField.control.append(dueRow);
    form.append(dueField.wrap);
    els.due = due;

    // 分组
    const groupField = field('分组', 'detail-group');
    const select = el('select', 'field__input');
    select.id = 'detail-group';
    select.addEventListener('change', () => {
      actions.setField(task.id, { groupId: select.value }, true);
      actions.flush();
    });
    groupField.control.append(select);
    form.append(groupField.wrap);
    els.group = select;

    // 备注
    const noteField = field('备注', 'detail-note');
    const note = el('textarea', 'field__textarea');
    note.id = 'detail-note';
    note.rows = 3;
    note.placeholder = '写点什么…';
    note.value = task.note;
    note.addEventListener('input', () => {
      els.autoGrow();
      actions.setField(task.id, { note: note.value });
    });
    note.addEventListener('blur', () => actions.flush());
    noteField.control.append(note);
    form.append(noteField.wrap);
    els.note = note;

    els.autoGrow = () => {
      note.style.height = 'auto';
      note.style.height = `${note.scrollHeight}px`;
    };

    // 子任务
    const subtaskField = field('子任务');
    const list = el('ul', 'subtask-list');
    const addInput = el('input', 'subtask-add__input');
    addInput.type = 'text';
    addInput.placeholder = '添加子任务，回车确认';
    addInput.autocomplete = 'off';
    addInput.setAttribute('aria-label', '新子任务');
    addInput.setAttribute('enterkeyhint', 'done');
    addInput.addEventListener('keydown', (event) => {
      if (event.key !== 'Enter') return;
      event.preventDefault();
      const text = addInput.value.trim();
      if (text === '') return;
      addInput.value = '';
      actions.addSubtask(task.id, text);
      addInput.focus();
    });
    subtaskField.control.append(list, addInput);
    form.append(subtaskField.wrap);
    els.subtasks = list;
    els.subtaskAdd = addInput;
    els.subtaskRows = new Map();

    // 元信息
    const meta = el('dl', 'detail__meta');
    form.append(meta);
    els.meta = meta;

    // 删除
    const remove = el('button', 'detail__delete');
    remove.type = 'button';
    remove.textContent = '删除任务';
    remove.addEventListener('click', () => {
      const ok = window.confirm(`确定删除「${task.title}」吗？\n\n这个操作没法撤销。`);
      if (ok) actions.deleteTask(task.id);
    });
    form.append(remove);

    root.append(form);
    els.autoGrow();
  }

  // ---------- 子任务 ----------

  function renderSubtasks(task) {
    els.subtasks.textContent = '';
    els.subtaskRows = new Map();

    for (const sub of task.subtasks) {
      const li = el('li', 'subtask');
      li.dataset.subtaskId = sub.id;

      const check = el('button', 'subtask__check');
      check.type = 'button';
      check.setAttribute('role', 'checkbox');
      check.setAttribute('aria-label', `切换子任务「${sub.text}」`);
      const tick = el('span', 'subtask__tick');
      tick.textContent = '✓';
      tick.setAttribute('aria-hidden', 'true');
      check.append(tick);
      check.addEventListener('click', () => {
        actions.toggleSubtask(task.id, sub.id);
        actions.flush();
      });

      const text = el('input', 'subtask__text');
      text.type = 'text';
      text.value = sub.text;
      text.autocomplete = 'off';
      text.setAttribute('aria-label', '子任务内容');
      text.addEventListener('input', () => {
        actions.setSubtask(task.id, sub.id, { text: text.value });
      });
      text.addEventListener('blur', () => actions.flush());

      const remove = el('button', 'icon-button subtask__delete');
      remove.type = 'button';
      remove.textContent = '×';
      remove.setAttribute('aria-label', `删除子任务「${sub.text}」`);
      remove.addEventListener('click', () => {
        actions.deleteSubtask(task.id, sub.id);
        actions.flush();
      });

      li.append(check, text, remove);
      els.subtasks.append(li);
      els.subtaskRows.set(sub.id, { li, check, text });
    }
  }

  function syncSubtasks(task) {
    for (const sub of task.subtasks) {
      const row = els.subtaskRows.get(sub.id);
      if (!row) continue;
      row.check.classList.toggle('subtask__check--on', sub.done);
      row.check.setAttribute('aria-checked', String(sub.done));
      row.li.classList.toggle('subtask--done', sub.done);
      if (document.activeElement !== row.text) row.text.value = sub.text;
    }
  }

  // ---------- 同步 ----------

  function syncControls(state, task) {
    const active = document.activeElement;

    // 每个输入框：正被编辑就别去碰它，否则光标会跳、字会丢
    if (active !== els.title) els.title.value = task.title;

    els.important.classList.toggle('toggle--on', task.important);
    els.important.setAttribute('aria-checked', String(task.important));

    els.done.classList.toggle('toggle--on', task.done);
    els.done.setAttribute('aria-checked', String(task.done));

    if (active !== els.due) els.due.value = task.due ?? '';

    const groups = sortedGroups(state);
    const groupKey = groups.map((g) => `${g.id}:${g.name}`).join('|');
    if (els.group.dataset.key !== groupKey) {
      els.group.textContent = '';
      for (const group of groups) {
        const option = document.createElement('option');
        option.value = group.id;
        option.textContent = group.name === '' ? '未命名分组' : group.name;
        els.group.append(option);
      }
      els.group.dataset.key = groupKey;
    }
    if (active !== els.group) els.group.value = task.groupId;

    if (active !== els.note) {
      els.note.value = task.note;
      els.autoGrow();
    }

    // 子任务 id 序列变了才重建，避免打字时输入框被换掉
    const key = task.subtasks.map((s) => s.id).join('|');
    if (key !== subtaskKey) {
      subtaskKey = key;
      renderSubtasks(task);
    } else {
      syncSubtasks(task);
    }

    els.meta.textContent = '';
    els.meta.append(
      metaRow('创建于', stamp(task.createdAt)),
      metaRow('完成于', stamp(task.completedAt)),
    );

    if (groupNameEl) {
      const group = getGroup(state, task.groupId);
      groupNameEl.textContent = group ? group.name : '';
    }
  }

  // ---------- 渲染入口 ----------

  function render(state, taskId) {
    const task = getTask(state, taskId);

    if (!task) {
      currentId = null;
      root.textContent = '';
      if (groupNameEl) groupNameEl.textContent = '';

      const box = el('div', 'empty-state');
      const title = el('p', 'empty-state__title');
      title.textContent = '这个任务不存在';
      const hint = el('p', 'empty-state__hint');
      hint.textContent = '它可能已经被删掉了';
      box.append(title, hint);
      root.append(box);
      return;
    }

    if (currentId !== taskId) {
      currentId = taskId;
      build(state, task);
    }

    syncControls(state, task);
  }

  return { render };
}
```

```js
// 入口：装载数据、装配路由与视图、统一处理写盘。

import { createStorage } from './storage.js';
import { createRouter, ROUTE_TASK } from './router.js';
import { createListView } from './list-view.js';
import { createDetailView } from './detail-view.js';
import {
  newId,
  getTask,
  sortedGroups,
  addTask,
  deleteTask,
  toggleTaskDone,
  toggleTaskImportant,
  updateTask,
  renameGroup,
  deleteGroup,
  moveTask,
  moveGroup,
  addSubtask,
  updateSubtask,
  deleteSubtask,
} from './store.js';

const notice = document.getElementById('notice');
const viewList = document.getElementById('view-list');
const viewDetail = document.getElementById('view-detail');
const groupList = document.getElementById('group-list');
const detailScroll = document.getElementById('detail-scroll');
const detailBack = document.getElementById('detail-back');
const detailGroupName = document.getElementById('detail-group-name');
const addTaskButton = document.getElementById('add-task-button');

const storage = createStorage();
const loaded = storage.load();

let state = loaded.state;
let warnedAboutSave = false;
let saveTimer = 0;

/** 顶部提示条。传空字符串就收起。 */
function showNotice(text) {
  notice.textContent = text ?? '';
  notice.hidden = !text;
}

/** 真正写盘。 */
function persist() {
  if (loaded.readonly) return;

  const result = storage.save(state);
  if (result.ok) {
    warnedAboutSave = false;
    return;
  }
  if (warnedAboutSave) return;

  warnedAboutSave = true;
  showNotice(
    result.reason === 'quota'
      ? '本地存储已满，这次的改动可能没保存。去右上角 ⋯ 里导出备份。'
      : '保存到本地失败，这次的改动可能没保存。去右上角 ⋯ 里导出备份。',
  );
}

/** 200ms 防抖写盘，给文本输入用。 */
function schedulePersist() {
  if (saveTimer) clearTimeout(saveTimer);
  saveTimer = setTimeout(() => {
    saveTimer = 0;
    persist();
  }, 200);
}

/** 立刻把还没落盘的改动写下去。切 App、锁屏、失焦时都靠它。 */
function flushSave() {
  if (saveTimer) {
    clearTimeout(saveTimer);
    saveTimer = 0;
  }
  persist();
}

/**
 * 更新状态并安排写盘。
 * immediate 为真时立刻写；否则防抖 200ms。
 * 列表隐藏时不重画列表，省掉打字过程中的无谓开销——
 * 回到列表时 applyRoute 会补一次渲染。
 */
function apply(nextState, immediate) {
  if (nextState === state) return;
  state = nextState;

  if (immediate) {
    if (saveTimer) {
      clearTimeout(saveTimer);
      saveTimer = 0;
    }
    persist();
  } else {
    schedulePersist();
  }

  if (!viewList.hidden) listView.render(state);
}

const listView = createListView({
  root: groupList,
  actions: {
    openTask: (taskId) => router.goToTask(taskId),
    toggleDone: (taskId) => apply(toggleTaskDone(state, taskId), true),
    deleteTask: (taskId) => apply(deleteTask(state, taskId), true),
    addTask: (groupId, title) => {
      apply(addTask(state, { id: newId('t'), groupId, title }), true);
    },
    renameGroup: (groupId, name) => apply(renameGroup(state, groupId, name), true),
    deleteGroup: (groupId) => apply(deleteGroup(state, groupId), true),
    moveTask: (taskId, groupId, index) => {
      apply(moveTask(state, taskId, groupId, index), true);
    },
    moveGroup: (groupId, index) => apply(moveGroup(state, groupId, index), true),
  },
});

const detailView = createDetailView({
  root: detailScroll,
  groupNameEl: detailGroupName,
  actions: {
    setField: (taskId, patch, immediate = false) => {
      apply(updateTask(state, taskId, patch), immediate);
      detailView.render(state, taskId);
    },
    toggleImportant: (taskId) => {
      apply(toggleTaskImportant(state, taskId), true);
      detailView.render(state, taskId);
    },
    toggleDone: (taskId) => {
      apply(toggleTaskDone(state, taskId), true);
```

```js
// 弹出菜单。分组标题的 ⋯ 和顶栏的 ⋯ 共用。

export function createPopupMenu() {
  let open = null;

  function close() {
    if (!open) return;
    open.element.remove();
    const { onClose } = open;
    open = null;
    if (onClose) onClose();
  }

  document.addEventListener('click', close);
  window.addEventListener('scroll', close, true); // 捕获阶段，内层容器滚动也算
  window.addEventListener('resize', close);

  function show(anchor, items, onClose) {
    close();

    const menu = document.createElement('div');
    menu.className = 'menu';
    menu.setAttribute('role', 'menu');

    for (const item of items) {
      const button = document.createElement('button');
      button.className = 'menu__item';
      button.type = 'button';
      button.setAttribute('role', 'menuitem');
      if (item.danger) button.classList.add('menu__item--danger');
      button.textContent = item.label;
      button.addEventListener('click', () => {
        close();
        item.run();
      });
      menu.append(button);
    }

    document.body.append(menu);

    // 贴住锚点右下角，并保证不超出视口
    const rect = anchor.getBoundingClientRect();
    const width = menu.offsetWidth;
    const height = menu.offsetHeight;
    const left = Math.min(
      Math.max(8, rect.right - width),
      Math.max(8, window.innerWidth - width - 8),
    );
    const below = rect.bottom + 4;
    const top = below + height > window.innerHeight - 8
      ? Math.max(8, rect.top - height - 4)
      : below;

    menu.style.left = `${left}px`;
    menu.style.top = `${top}px`;

    open = { element: menu, onClose };
  }

  return { show, close };
}
```

```js
import { writeFileSync, mkdirSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const OUT_DIR = join(dirname(fileURLToPath(import.meta.url)), '..', 'icons');

// 取自 css/tokens.css 的 --color-accent（亮色）与 --color-on-accent
const BACKGROUND = [0x23, 0x83, 0xE2];
const FOREGROUND = [0xFF, 0xFF, 0xFF];

// ---------- PNG 编码 ----------

const CRC_TABLE = (() => {
  const table = new Int32Array(256);
  for (let n = 0; n < 256; n += 1) {
    let c = n;
    for (let k = 0; k < 8; k += 1) {
      c = (c & 1) ? (0xEDB88320 ^ (c >>> 1)) : (c >>> 1);
    }
    table[n] = c;
  }
  return table;
})();

function crc32(buffer) {
  let c = 0xFFFFFFFF;
  for (const byte of buffer) {
    c = CRC_TABLE[(c ^ byte) & 0xFF] ^ (c >>> 8);
  }
  return (c ^ 0xFFFFFFFF) >>> 0;
}

function chunk(type, data) {
  const typeBuffer = Buffer.from(type, 'ascii');
  const out = Buffer.alloc(8 + data.length + 4);
  out.writeUInt32BE(data.length, 0);
  typeBuffer.copy(out, 4);
  data.copy(out, 8);
  out.writeUInt32BE(crc32(Buffer.concat([typeBuffer, data])), 8 + data.length);
  return out;
}

function encodePng(size, rgba) {
  const signature = Buffer.from([0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A]);

  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr[8] = 8;  // 每通道 8 位
  ihdr[9] = 6;  // RGBA
  ihdr[10] = 0; // 压缩方式
  ihdr[11] = 0; // 滤波方式
  ihdr[12] = 0; // 不隔行

  const stride = size * 4;
  const raw = Buffer.alloc((stride + 1) * size);
  for (let y = 0; y < size; y += 1) {
    raw[y * (stride + 1)] = 0; // 每行的滤波字节
    rgba.copy(raw, y * (stride + 1) + 1, y * stride, (y + 1) * stride);
  }

  return Buffer.concat([
    signature,
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw, { level: 9 })),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

// ---------- 绘制 ----------

const clamp01 = (v) => (v < 0 ? 0 : v > 1 ? 1 : v);

/** 圆角矩形的覆盖率，软边约 1px，用来抗锯齿。 */
function roundedSquareAlpha(px, py, size, radius) {
  const half = size / 2;
  const dx = Math.abs(px - half) - (half - radius);
  const dy = Math.abs(py - half) - (half - radius);
  const outside = Math.hypot(Math.max(dx, 0), Math.max(dy, 0));
  const inside = Math.min(Math.max(dx, dy), 0);
  return clamp01(0.5 - (outside + inside - radius));
}

/** 线段的覆盖率（带圆头）。 */
function segmentAlpha(px, py, a, b, halfWidth) {
  const abx = b[0] - a[0];
  const aby = b[1] - a[1];
  const len2 = abx * abx + aby * aby;
  const t = len2 === 0
    ? 0
    : Math.max(0, Math.min(1, ((px - a[0]) * abx + (py - a[1]) * aby) / len2));
  const cx = a[0] + abx * t;
  const cy = a[1] + aby * t;
  return clamp01(0.5 - (Math.hypot(px - cx, py - cy) - halfWidth));
}

function drawIcon(size) {
  const rgba = Buffer.alloc(size * size * 4);
  const radius = size * 0.22;
  const stroke = size * 0.085;

  // 一个勾：先向右下，再向右上
  const p1 = [size * 0.28, size * 0.52];
  const p2 = [size * 0.44, size * 0.68];
  const p3 = [size * 0.73, size * 0.34];

  for (let y = 0; y < size; y += 1) {
    for (let x = 0; x < size; x += 1) {
      const px = x + 0.5;
      const py = y + 0.5;

      const background = roundedSquareAlpha(px, py, size, radius);
      const tick = Math.max(
        segmentAlpha(px, py, p1, p2, stroke / 2),
        segmentAlpha(px, py, p2, p3, stroke / 2),
      );

      const i = (y * size + x) * 4;
      rgba[i] = Math.round(BACKGROUND[0] * (1 - tick) + FOREGROUND[0] * tick);
      rgba[i + 1] = Math.round(BACKGROUND[1] * (1 - tick) + FOREGROUND[1] * tick);
      rgba[i + 2] = Math.round(BACKGROUND[2] * (1 - tick) + FOREGROUND[2] * tick);
      rgba[i + 3] = Math.round(background * 255);
    }
  }

  return rgba;
}

// ---------- 输出 ----------

mkdirSync(OUT_DIR, { recursive: true });

const targets = [
  ['icon-192.png', 192],
  ['icon-512.png', 512],
  ['apple-touch-icon.png', 180],
];

for (const [name, size] of targets) {
  const file = join(OUT_DIR, name);
  writeFileSync(file, encodePng(size, drawIcon(size)));
  console.log(`写入 ${name}（${size}×${size}）`);
}
```
